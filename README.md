# 🎮 Análisis de Ventas de Videojuegos

Aplicación de línea de comandos desarrollada en **Python** para consultar y analizar una base de datos de videojuegos. Proyecto colaborativo desarrollado en equipo de 3 personas.

## ✨ Funcionalidades

- Filtrado de juegos por **género** o **consola**
- Búsqueda de juegos lanzados en un **rango de fechas**
- Generación de un **informe general** con estadísticas del catálogo
- Base de datos en formato JSON con información como título, género, consola y fecha de lanzamiento

## 🛠️ Tecnologías

- Python 3
- JSON

## 🚀 Uso

### Requisitos previos

- Python 3.8 o superior

### Ejecución

```bash
# Clonar el repositorio
git clone https://github.com/Jonrn16/proyecti-videojuegos.git
cd proyecti-videojuegos

# Ejecutar la aplicación
python main.py
```

La aplicación se ejecuta en la terminal y presenta un menú interactivo con las opciones disponibles.
